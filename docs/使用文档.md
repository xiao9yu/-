# 教育智能体平台 · 使用文档

面向教师、学生、管理员的操作手册。介绍每个功能怎么点、每一步会看到什么。

---

## 1. 启动平台（第一次使用）

平台是前后端分离的，要开**两个终端窗口**：一个跑后端（端口 8000），一个跑前端（端口 5173）。两个都要保持开着，关掉窗口服务就停了。

项目目录：仓库根目录（本文件所在目录的上一级）。

环境要求：Python 3.10+（本机 3.12.7）、Node.js 18+（本机 v24.17.0）。

### 1.1 终端 A：启动后端

```bat
cd <项目目录>\backend
pip install -r requirements.txt
python -m scripts.seed_demo_data
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

四条命令的作用：进入后端目录 → 装依赖 → 写入演示数据（账号、演示课程、知识库文档、知识图谱与习题）→ 启动服务（**端口 8000**，vite 代理已指向这里）。

看到下面这行就说明后端起来了：

```
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
```

第二条和第三条只在第一次需要，之后每天启动只跑第一条和第四条。后端不要加 `--reload`：Windows 下重载会派生子进程，Ctrl-C 退出时可能残留进程占用端口。

启动后第一次要预热模型（bge-m3 嵌入、重排、FunASR），约 1~2 分钟，期间接口无响应属正常，看到 `ASR 模型预热完成 / 流式语音预热完成` 才可以用。

### 1.2 终端 B：启动前端

```bat
cd <项目目录>\frontend
npm install
npm run dev
```

看到 `Local: http://localhost:5173/` 就说明前端起来了。`npm install` 同样只在第一次需要。

### 1.3 打开网页

浏览器（推荐 Chrome / Edge）访问：

```
http://localhost:5173
```

也可以直接在终端 B 里按住 `Ctrl` 点那行 `Local:` 链接打开。

### 1.4 关于 AI 功能的 API Key

登录、浏览、上传、检索这些不需要 Key。但 **AI 生成类功能**（备课生成、助教问答、错题解析）要调用 DeepSeek，需要先配置：

```bat
cd <项目目录>\backend
copy .env.example .env
notepad .env
```

在打开的记事本里把 `DEEPSEEK_API_KEY=sk-你的key` 换成真实 Key，保存关闭，然后重启终端 A 的后端。

如果之前配过就不用重复操作。

### 1.5 停止与重启

- 停止：在对应终端窗口按 `Ctrl + C`。
- 重启：重新执行 1.1 的第四条 / 1.2 的第三条命令。
- 改代码后后端不会自动重启，需要手动 Ctrl-C 再重新执行启动命令（见 1.1）。

### 1.6 启动失败怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 网页打不开、一直转圈 | 前端没起来 | 看终端 B 有没有 `Local:` 那行 |
| 页面能开但登录报网络错误 | 后端没起来 | 看终端 A 是否还在运行 |
| `端口已被占用 / port in use` | 上一次的进程没退 | 换端口，或结束占用进程后重启 |
| `'pip' / 'npm' 不是内部或外部命令` | Python / Node 没装或没进 PATH | 装好后重开终端 |
| AI 生成报错、返回空 | 没配 `DEEPSEEK_API_KEY` | 按 1.4 配置后重启后端 |
| 助教首次提问卡很久 | 在下载向量模型（约 3GB） | 等下载完；慢可先设 `set HF_ENDPOINT=https://hf-mirror.com` 再启动后端 |

## 2. 登录

浏览器（推荐 Chrome / Edge）打开 `http://localhost:5173`，进入登录页。

左侧是平台介绍，右侧是登录表单。表单下方列出四个演示账号，点账号行右边的「填入」可以直接把用户名密码填进输入框，再点「登 录」。

| 角色 | 账号 | 密码 | 能看到的模块 |
|---|---|---|---|
| 管理员 | admin | admin123 | 首页、智能备课、智能助教（含公共知识库管理） |
| 教师 | teacher | teacher123 | 首页、智能备课、智能助教 |
| 学生 | student | student123 | 首页、智能备课、智能助教、个性化学习 |
| 就业指导 | counselor | counselor123 | 首页、智能备课、智能助教 |

说明：

- 「个性化学习」菜单只对学生角色显示。
- 密码输入框右侧的眼睛图标可以切换明文显示。
- 输入完可以直接按回车登录。
- 账号或密码错误时，页面右上角会弹红色提示。

### 退出登录

点右上角的用户头像区域（头像 + 姓名 + 角色）即可退出，回到登录页。

---

## 3. 界面布局

登录后是统一的三区布局：

- **左侧深色侧边栏**：顶部是平台标识，中间是「工作台」菜单（首页 / 智能备课 / 智能助教 / 个性化学习），当前所在模块会高亮。
- **顶栏**：左边显示当前页面标题，右边是用户信息与退出入口。
- **主内容区**：当前模块的操作界面。

---

## 4. 首页

登录后的落地页，分四块：

- **欢迎横幅**：按当前时间显示问候语、今天的日期和星期。
- **数据统计**：三张卡片显示「我的课程」数量、「知识库文档」数量、「智能模块」数量。点卡片可直接跳到对应模块。
- **功能模块**：平台各模块的卡片一览，带「已上线 / 规划」状态标签，点卡片进入模块。
- **快速开始**：三步上手指引，按角色说明先做什么。

## 5. 智能备课（教师）

侧边栏点「智能备课」。整个流程是：建课程 → 上传资源 → AI 生成 → 保存为教案 → 编辑 → 导出。

### 5.1 课程列表与新建课程

进入后看到课程卡片列表，每张卡显示课程名、学科标签和描述。

新建课程：点右上角「新建课程」，弹窗里填三项——

| 字段 | 说明 | 示例 |
|---|---|---|
| 课程名 | 必填 | 人工智能导论 |
| 学科 | 默认已填「人工智能」 | 人工智能 |
| 描述 | 可留空 | 面向大二学生的导论课 |

点「创建」后列表刷新。点任意课程卡进入课程详情页。

### 5.2 上传校本资源

课程详情页左侧是「校本资源」卡片，这里的资源供 AI 生成时引用。

1. 点「上传资源文件（docx/pptx/xlsx/pdf）」选择本地文件，上传成功后右上角提示「资源已上传」，文件出现在下方列表。
2. 列表里每个文件按类型显示不同颜色图标（PDF 红、Word 蓝、表格绿、图片紫）。
3. 点文件右侧的红色垃圾桶图标删除该资源。

### 5.3 检索资源

在资源卡片的搜索框输入关键词（如「梯度下降」），点「检索」。下方「检索结果」列出命中片段，每条显示引用编号、相关度分值和原文摘录。这一步用来确认资源里到底有没有你要的内容。
