# 教育智能体平台（edu-agent-platform）设计文档

- 日期：2026-09-14
- 项目来源：Agent 数字人项目-教育智能体方向 实训工单 16~20（八维文化与产业研究院）
- 状态：已与用户确认

## 1. 背景与范围

本实训共 5 份工单，交付一个面向高职院校的教育智能体平台：

| 工单 | 任务 | 产出物 | 工时 |
|---|---|---|---|
| 16【必选】 | 需求分析与软件架构设计 | 架构设计文档（七章结构） | 1 人日 |
| 17 | 智能备课：LLM+RAG 生成教案/课件/习题/月考试题，富文本编辑、资源检索引用、多格式导出、版本管理 | 前后端代码 + UML/接口/数据库设计 + 测试用例及结果 | 2 人日 |
| 18 | 智能助教：多模态文档解析 + 公共/私有知识库 + 混合检索重排序 RAG 问答 | 同上 | 2 人日 |
| 19 | 个性化学习推荐：学生画像、知识图谱路径推荐、自适应练习、AIGC 错题本 | 同上 | 2 人日 |
| 20 | 面试 AI 复盘：录音转文字、问题评分、总体评价、AI 优化版对话 | 同上 | 2 人日 |

代码注释需包含工单编号（各工单备注要求）。

## 3. 总体架构（四层）

```
┌─────────────────────────────────────────────────────┐
│ 前端层  Vue3 + Vite + Element Plus + Pinia + Router │
│        登录 → 首页仪表盘 → 智能备课/智能助教/       │
│        个性化学习/面试复盘 四个模块页               │
├─────────────────────────────────────────────────────┤
│ 后端层  FastAPI（REST API + JWT 认证）              │
│        /auth  /prep(备课)  /kb(知识库问答)           │
│        /learn(推荐)  /interview(复盘)  /files       │
├─────────────────────────────────────────────────────┤
│ 智能服务层                                           │
│  LLM网关(DeepSeek)  RAG引擎(混合检索+重排)          │
│  文档解析管线(多模态)  ASR服务(FunASR)  画像/推荐    │
├─────────────────────────────────────────────────────┤
│ 数据层  SQLite(SQLAlchemy,可切MySQL) + Milvus Lite   │
│        向量库 + Neo4j 知识图谱 + 本地文件存储        │
└─────────────────────────────────────────────────────┘
```

模块间通过定义清晰的接口通信，每个服务可独立测试。

## 4. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 大模型 | DeepSeek API chat 模型 | 便宜稳定，OpenAI SDK 兼容，JSON 模式输出结构化内容 |
| Embedding | 本地 bge-m3（sentence-transformers，CPU 可跑） | DeepSeek 无 embedding API；本地免费离线，中文效果好 |
| 向量库 | **Milvus Lite**（pymilvus 本地模式，无需 Docker） | 工单 17 推荐（Milvus/FAISS/ES 中选 Milvus）；FAISS 作兜底，接口封装成可切换 |
| 重排序 | RRF 融合（向量+BM25）粗排 → 本地 bge-reranker 精排 | 满足工单 18 重排序要求，零额外 API |
| 文档解析 | PyMuPDF / python-docx / python-pptx / openpyxl + PaddleOCR | 全本地免费，覆盖工单 18 多模态要求（文本/表格/图片/公式） |
| 语音识别 | 本地 FunASR（paraformer-zh） | 离线无限用 |
| 知识图谱 | Neo4j Community（Windows 一键安装） | 工单 19 建议；装不上则退化为 SQL 表 + networkx，不影响验收 |
| 业务数据库 | SQLite（开发期）+ SQLAlchemy | 零安装；模型即"数据库设计"产出物，切 MySQL 只改配置 |
| 前端 | Vue3 + Vite + Element Plus + Pinia + wangeditor 富文本 | 前后端分离代码交付 |

## 5. 公共底座（建一次，四模块复用）

1. **认证与角色**：JWT 登录，4 种角色——教师/学生/就业指导/管理员。
2. **LLM 网关**：统一封装 DeepSeek 调用（超时重试、流式输出、JSON 结构化解析、用量日志），各模块只调网关。
3. **文件服务**：上传/下载/预览，`uploads/` 目录 + files 表。
4. **文档解析管线**：PDF/Word/PPT/Excel/图片 → 文本块、表格块、图片块（OCR 出文字+保留原图引用）、公式块 → 分块 → 向量化。工单 18 为主用户，工单 17 资源检索复用。
5. **RAG 引擎**：向量检索（Milvus）+ 关键词检索（BM25）混合检索 → RRF 融合重排 → 返回带原文出处/图片引用。

## 6. 模块设计

### 6.1 工单 17 智能备课

核心链路：教师登录 → 填课程信息（课程名/章节/教学目标/课时）→ 选生成类型（教案/课件大纲/习题/案例/月考试题）→ LLM 网关，如需校本资源先 RAG 检索拼入 prompt → DeepSeek JSON 结构化生成初稿 → 前端 wangeditor 富文本编辑 → 插入多媒体 → 导出 Word/PPT/PDF（python-docx/python-pptx/reportlab）→ 每次保存存版本快照，支持历史回溯。

- 习题 JSON 结构：`{题干, 选项, 答案, 解析, 知识点, 难度}`（供工单 19 直接复用）
- 资源检索引用：关键词+向量双检索，一键插入正文，自动生成 `[1] 来源：教材名-章节` 引用标注
- 月考试题：按知识点分布+题型模板批量生成，自动组卷导出
- 协同编辑 V1 简化：多人可编辑 + 版本快照回溯；Yjs 实时同步列为加分项（验收标准不强制）

数据表：`courses`、`lessons`（教案/课件，存 JSON 结构化内容）、`exercises`、`version_snapshots`、`media_files`、`citations`。

### 6.2 工单 18 智能助教（多模态 RAG）

核心链路：师生上传文档（PDF/Word/PPT/Excel/图片）到私有库或公共库 → 多模态解析（文本块/表格块结构化/图片块 OCR+原图/公式块 图片+LaTeX）→ 分块 → bge-m3 向量化入 Milvus → 提问 → 混合检索（私有库+公共库各取向量 top-k 与 BM25 top-k）→ RRF 融合 + bge-reranker 精排 → DeepSeek 流式生成回答，附引用出处（文件名+位置）+原文摘录+图片/表格直接展示。

- 私有库隔离：检索按 `user_id` 过滤
- 公共库由管理员预置（人工智能专业课程教材、大纲等）
- 回答可溯源：前端引用卡片，点击展开原文
- 参考工单给出的 RAG-Anything 思路，但不引入其重依赖（RAGFlow），自建组件实现同等效果

数据表：`knowledge_bases`（public/private+所属人）、`documents`、`chunks`（类型：text/table/image/formula）、`qa_history`。

### 6.3 工单 19 个性化学习推荐

核心链路（按工单用户流程）：
1. 初始化：复用工单 17 生成的课程教案与试题；
2. 登录与诊断：首次登录做诊断测试（17 的试题）或导入历史成绩 → 初始画像；
3. 仪表盘：画像雷达图 + 推荐学习路径 + 今日任务；
4. 路径推荐：Neo4j 知识图谱（知识点前后置关系）→ 未掌握知识点+前置依赖拓扑排序，前端展示"为什么推荐学这个"（可解释性，工单要求）；
5. 自适应练习：正确率>80% 升难度，<50% 降难度；
6. AIGC 错题本：答错自动入错题本 → 按工单 prompt 结构（原题干+错误答案+正确答案+知识点+常见错误类型）输出 解析+错误原因+2~3 道变式题；
7. 持续迭代：画像随答题、助教提问等行为更新（加权+时间衰减）。

数据表：`student_profiles`、`mastery_records`、`practice_records`、`wrong_questions`、`learning_paths`；Neo4j：`知识点—[前置]→知识点`。协同过滤用 numpy 实现（相似学生推荐）。

### 6.4 工单 20 面试 AI 复盘

核心链路：
1. 面试列表：学生填报 + 就业指导 Excel 模板批量导入（pandas）；字段：学生/岗位/轮次形式/城市时间/上报人/上报时间；学生 2 天内可改"待完善"记录（上报人变学生名）；
2. 上传录音 → FunASR 转文字 → DeepSeek：文本纠错+问题提取（Q&A 结构化）→ 每题评分（1~10）+点评（结合岗位核心技术点知识库）→ 总体评分+总评+自我介绍点评+改进建议；
3. 复盘详情页：总体评价区 / 问题解析区（每题分+点评）/ 面试对话区（左 AI 优化版回答，右完整原记录对照）。

数据表：`interviews`、`interview_qa`、`interview_reports`、`job_skills`。

## 7. 工单 16 文档产出安排

按工单要求七章结构撰写，存项目 `docs/` 目录，1 人日（排期 D1）完成。文档中画的架构即本项目真实架构（设计文档即架构文档底稿），不写虚构架构。

七章：一、项目背景；二、需求分析（目标用户、主要功能场景）；三、软件设计架构（总体架构、详细分层说明）；四、各场景技术选型分析；五、数据安全与合规；六、实施建议（资源规划及工时安排）。

## 8. 错误处理与测试策略

- LLM 网关：超时 3 次指数退避重试、JSON 解析失败自动修复重试、失败降级为友好提示（不白屏）；
- FastAPI 全局异常处理器，所有接口返回结构化错误 JSON；
- pytest 单测覆盖服务层：文档解析、RAG 检索重排、画像更新、自适应难度、复盘评分解析；
- 每工单单独出测试用例文档+测试结果（验收要求）；前端出功能测试清单；
- 预置一套人工智能专业课程演示数据（教材 PDF、PPT、试题、面试录音样例），验收现场直接演示全链路。

## 11. 风险与缓冲

| 风险 | 应对 |
|---|---|
| Milvus Lite 在本机跑不起来 | 接口封装，一行配置切 FAISS（同为工单推荐） |
| Neo4j 安装失败 | 退化为 SQL 表 + networkx，功能不受影响 |
| bge-m3 模型下载慢/内存不足 | 备选 bge-small-zh-v1.5（约 100MB，轻量） |
| DeepSeek API 限流/欠费 | LLM 网关统一重试与降级提示，不阻塞其他功能演示 |
| 前端工作量超预期 | 每模块先保核心链路页面（列表+表单+结果页），富交互后置 |
